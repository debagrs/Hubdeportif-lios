# COMECE AQUI

Esta é a versão final do Hub para **5 estudantes**, com:

- Neon — banco;
- Cloudinary — imagens;
- Brevo ou Resend — e-mail;
- Vercel — publicação/API;
- GitHub — código.

## NÃO configurar

- Cloudflare R2;
- Supabase;
- Turso;
- Vercel Blob.

## Fluxo correto dos alunos

A administradora **não cria senha de aluno**.

1. Administradora entra no painel.
2. Abre **Estudantes**.
3. Digita o e-mail e envia o convite.
4. O aluno recebe o link.
5. O aluno cria a própria conta, nome, URL e senha.
6. O aluno passa a editar somente o próprio portfólio.
7. Se esquecer a senha, usa **Esqueci minha senha**.

Leia `PASSO-A-PASSO-INTEGRACAO.md` antes de mexer na Vercel.
